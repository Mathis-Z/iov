Reading the map

One dot per CVE. Up is more severe (CVSS), right is more likely to be exploited (EPSS, log scale). Colour is the most urgent priority the CVE has on any host, so a severe, likely-exploited CVE shown as Plan or Low is one the IoV verdicts have defused. Larger dots affect more hosts.
